# Bandung concept portraits

This archive holds 268 concept artworks in six physically separate semantic folders. They are **not** the 32 active dialogue expression strips.

| Folder | File pattern | Count | Intended role |
| --- | --- | ---: | --- |
| `neighborhood/` | K01–K30 | 30 | Local neighborhood NPC concepts |
| `specialists/` | N01–N06 | 6 | New specialist NPC concepts |
| `civic/` | P01–P02 | 2 | Civic character concepts |
| `residents/` | R001… | 179 | Resident illustrations for city exploration |
| `professions/` | work-A/C | 32 | Occupation art for known characters |
| `phone/` | phone-A/C | 19 | Phone and profile art |

For runtime access use `src/lib/game/bandung-concept-portrait.ts`, not hardcoded filenames. The old flat URL paths were moved, so references to those URLs must be migrated. See `game-assets/catalog/asset-folder-migration-20261121.json` for the full relocation list and SHA checks.
