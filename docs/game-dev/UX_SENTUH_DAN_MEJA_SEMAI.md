# HUD sentuh dan interaksi kebun

YZ Phone menempati posisi pertama pada bilah utilitas HP. Empat panah memakai bentuk CSS yang sama. Kontrol arah memiliki sasaran sentuh minimal 44 piksel CSS dan tombol menonaktifkan seleksi teks.

Meja semai di samping rumah dapat diperiksa. Pada tahap kedua misi Nani, siram tanaman lalu periksa meja. Pemeriksaan tercatat dalam progres. Talud, bangku, dan bunga di sekitar rumah Widi digeser dari depan pintu. Petak (26,8) menjadi akses pintu.

Lima alur misi pribadi diuji pada model dengan sebagian prasyarat disiapkan. Uji browser sentuh pada 390 x 760 mencakup membuka dan menutup YZ Phone, memeriksa meja, ukuran panah, dan aturan seleksi teks. Pengujian perangkat fisik masih diperlukan.
