# Tidur, ritme hari, dan plaza pasar
Empat langkah luar ruangan yang berhasil memajukan jam satu menit. Sisa langkah disimpan. Pekerjaan kebun memakai tiga menit dan melempar pancing dua menit. Saat mengonfirmasi tidur, game menyimpan pergantian hari lalu menampilkan transisi pagi selama 1,8 detik dengan dukungan pengurangan gerakan.

Paving membentuk satu persegi panjang sampai tepi timur pasar. Lapak anyaman, tong, keranjang, peti hasil bumi, serta bangku ditata di sisi selatan agar koridor tengah tetap terbuka.
