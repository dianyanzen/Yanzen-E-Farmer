# Yanzen E-Farmer — AI Agent Instructions

Apply the project engineering skill at [Karpathy-inspired guidelines](.agents/skills/karpathy-guidelines/SKILL.md) to all development, debugging, review, and refactoring work.

These are locally adapted engineering guidelines, not an official Andrej Karpathy publication.

## Project priorities
1. Correct farm operations, accounting, payroll, harvest, and sales data.
2. Secure database access and protect production data.
3. Simple, maintainable implementations consistent with existing architecture.
4. Preserve YZ agricultural branding and mobile usability.
5. Verify changes before declaring completion.

Before editing, inspect the relevant code and explain assumptions. Prefer targeted changes over broad rewrites. Do not alter production deployment, secrets, database data, or security policies without explicit authorization. Report verification status accurately.
